# API Фильмотеки на FastAPI

Простое API для управления базой данных фильмов и жанров.

## Настройка и Запуск

1.  **Создание виртуального окружения:**
    ```bash
    py -m venv .venv
    ```

2.  **Активация виртуального окружения:**
    *   Windows (cmd/powershell):
        ```bash
        .venv\Scripts\activate
        ```
    *   Linux/macOS (bash/zsh):
        ```bash
        source .venv/bin/activate
        ```

3.  **Установка зависимостей:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Создание файла `.env`** (в корне проекта):
    Скопируйте содержимое из примера ниже или создайте свой файл:
    ```dotenv
    DB_NAME=movielib.db
    ```

5.  **Посев базы данных (первоначальное наполнение):**
    *   Убедитесь, что виртуальное окружение активировано.
    *   Запустите скрипт `seed.py`:
        ```bash
        py seed.py
        ```

6.  **Запуск сервера разработки FastAPI:**
    ```bash
    fastapi dev main.py
    ```

7.  **Документация API:**
    *   Откройте в браузере `http://127.0.0.1:8000/docs`
